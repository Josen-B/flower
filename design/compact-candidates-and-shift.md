# Flower 0.4.4：紧凑候选、Shift 模式切换与常用短语

本契约在用户已提交的 0.4.3 基线 `aa7380e00744ca562789ff278fd1850ae429a50e`
上增量实施，不回滚用户已有暂存或工作区改动。
覆盖旧文档冲突条款；固定 Program Files、安全门禁、相邻持久排序和混输预算不变。

## 候选窗

- 移除整个页脚（`-`、`+`、页码及其点击区域），减少对应高度，不保留空白行。
  引擎真实分页不变，`+/-`、PageUp/PageDown 和数字/鼠标候选选择继续有效。
  兼容布局字段可保留为 None，不新增不可见可点击按钮。
- 当前项背景从本项起点覆盖编号及实际显示文字，到文字末尾为止；不填满估算单元格。
  使用当前选中字体的 GDI 实际字宽测量，边界不超过本项单元格，省略文本同样裁剪。
  候选布局/数字索引/整项鼠标命中不变；高亮不是缩小点击区域。
  无法测量时保守限制在本项内，不借此修改分页估算或截断提交内容。

## Shift 行为（用户已明确选择）

- 默认中文。单独按下再松开 Shift 切换中英文；左右 Shift 等价，
  与其他按键搭配、Ctrl/Alt/Win 组合、重复按下均不得误切换。
  OnTestKeyDown/Up 为纯预测，不改变模式或提交；只在真实回调落实。
- 中文有未提交组词时，切换将整段 confirmed.raw + remaining raw 按原字母提交，
  包括已选中文但尚未最终上屏的片段；已提交的宿主文字完全不修改。
  此操作不产生 LearningEvent 或 PromotionEvent。
- 英文模式普通键直通宿主，再单独 Shift 恢复中文。模式为当前激活会话的临时状态，
  不写用户配置、不改系统默认输入法；失焦清理未完成手势，重新激活默认中文。
- 单独手势须读取线程键盘状态，已有字母/控制键按住、同时按双 Shift 或查询失败均拒绝。
  临时订阅 `ITfThreadMgrEventSink`，文档焦点变化及 context push/pop 推进独立 generation，
  即使切走再切回也不能恢复旧手势；订阅只持有 generation，避免服务引用环，解除有 RAII。
  保留键的真实回调也取消手势，不在纯 test 回调中作状态推断。
- 带组词的切换复用已有 edit request/token/epoch/context/claim 校验；
  只有文档编辑成功才发布新状态和英文模式。失败或失效不丢预编辑、不切模式。
  没有组词的切换不请求文档写锁；不能绕过真实焦点与激活线程检查。

## 安装后启动

默认勾选启动不变，仅以原普通用户启用 Flower，成功后退出，不打开设置窗口，
不自动持久创建配置，不改默认输入法。无参数 flower-settings 仍正常打开设置。
提升/查询失败/enable 失败保持拒绝与固定失败提示。
“启用”不等价当前焦点已切换，用户可用 Win+Space 选择。

## 常用短语

- 新增项目人工编写的常用短语 TSV，使用真实规范读音，明确人工权重非统计词频；
  保留项目许可与来源说明，不伪称来自原 CC-CEDICT 上游或扩大原核心覆盖数字。
  独立收录至少一百条日常表达，包括“我爱你”“不知道”“晚上好”等。
- 加入 builtin 共享索引，仍用既有 full/initial/mixed 解码，不新增拼写特例；
  `wan` 的 `wo'ai'ni` 与全拼 `wan` 同时可达，完整全拼仍优先，不删除“晚、万”等。
  数据随 ZIP 附带，包内哈希、manifest 独立数量与许可来源匹配。
  每条规范词 full/initial 实际可达，代表项可完整提交、规范学习身份不变。
- 不改上游 core/proper/base 字节，不自动启用 optional，不减少 16384/4096 预算、
  beam8 或 per-end4 来掩盖时延。

   英文直通和真实编辑成功/失效时模式一致性。

4. 常用数据完整合法性、full/initial 消费者、overlay隔离、组包边界；
   共享引擎变更后定向 session/router/native，严格 Clippy/格式。
5. 真实构建0.4.4，只读核验内外哈希、词库/许可、图标/版本/CLI，
