# Flower 输入与自定义安装目录

## 本轮范围

以当前 0.3.0 实现为基线，改进机器级自定义安装目录、常用字词排序与首字母简拼。
仓库 README 仅保留项目介绍、使用、开发入口和许可，详细契约集中在本目录。
用户已确认 0.3.0 可以输入大部分常用字；这不是所有宿主或新功能通过的证据。

## 自定义安装

- 默认仍为 Program Files，但不按盘符或 Program Files 白名单限制位置。
- `check-install-path --path` 保持只读。目标不存在时，仅将现有组件作为祖先检查；
  允许创建兄弟文件、子目录以及不影响路径替换的属性写入，仍拒绝普通主体删除、
  删除子项、修改 DACL/owner 或完全控制路径的权限。目标已存在则严格检查整个树。
  已确认的本地固定卷根不能像普通目录被删除/重命名；仅在该卷根的祖先检查中忽略
  对根本身的 DELETE 位，仍拒绝 FILE_DELETE_CHILD、WRITE_DAC、WRITE_OWNER 等权限。
  不把这一例外应用于任意子目录，不允许卷根作为安装目标。
- 新增显式 `prepare-install-path --path`，仅供提升后的安装流程准备目录。
  不修改任何已有目录的权限、owner 或内容；存在的不安全目录拒绝使用。
  缺失组件逐级使用创建时的受保护安全描述符：
  owner Administrators，SYSTEM/Administrators 完全控制，Users 读和执行，
  可向后代继承。不得先以继承权限创建再收紧，不接管竞争者已创建的同名路径。
- 创建期间保留已检查祖先和新目录的禁止删除共享句柄；创建完成严格复查。
  失败不复制载荷或注册，允许留下本次新建的空安全目录，不递归清理未知内容。
- 安装器目录页只预检，在复制前准备及复查，注册前、卸载前继续严格检查与哈希核对。
  不改 D 盘根或已有父目录 ACL；真正允许普通用户替换路径的祖先仍必须拒绝。
  错误文案区分不安全祖先/已有目标，并说明新目录由安装器保护。
- 此次不改变默认输入法、不自动停用/覆盖旧版或关闭用户应用。

## 常用排序

使用现有固定 jieba 快照的精确文字频率，不引入新的网络词库。
单字排序不再仅按静态档位与 Unicode 字序；保留所有已有读音、基线和扩展字，
频率是文字频率，不伪称各多音读音的频率。真实词组继续使用已有词级读音。
优先读音、其他基线读音、扩展读音三档保持严格顺序，各档内部按压缩文字频率排序，
权重保持接近原尺度，避免单字权重全面放大破坏组句。内置运行表不再叠加 MVP 演示
词条的人工权重；演示文件保留供小型 fixture 使用。常用词只依赖真实核心词组数据。
生成结果必须离线可复现，更新来源/许可/覆盖元数据及包校验，不手工硬编码示例排名。
学习、个人词典的既有权重语义与有界增量不扩大；同分使用稳定次序。

## 整词首字母

- 每个规范分音词条按每音节第一个 ASCII 字母建立只读索引，如 `ni'hao -> nh`、
  `zhong'guo -> zg`。仅至少两个音节且每字一音节的词条参与；不从连写演示词猜切分。
- 首字母输入是整词匹配，不做任意子串、单字首字母搜索、混合全拼简拼或缩写组句。
  含显式 `'` 的输入仍仅使用现有分音全拼规则。
- 候选顺序为完整全拼、完整组合、整词简拼、部分前缀；简拼按词权重稳定排序、
  去除已显示文字重复，不截断已有精确单字候选。索引在加载/overlay/学习快照变化时同步，
  不在每个按键中扫描整部词典，不污染进程内内置共享表。
- 简拼候选 comment 和学习事件保存规范完整读音；消耗范围是实际原始缩写字节数。
  既有键鼠选择、一次提交、退格撤回和隐私门禁保持不变。

## 验证与交付

按实际消费者覆盖目录 SDDL/分类/CLI/安装器接线、词频生成与包验证、
简拼索引及 overlay/learning、会话/router/候选和原生 TSF 编辑路径。
构建新版本制品，不覆盖 0.3.0；不在开发机执行安装或改真实用户配置。
新目录的管理员创建及另一机器实机输入仍分别记录，不将静态检查冒充安装验收。

## 0.4.1 输入与候选窗修订

用户确认 0.4.0 可在 `D:\Flower` 安装，但已有 `D:\software` 下仍拒绝；
Edge 等宿主不显示候选窗。此次仅递增补丁版本为 0.4.1，后续无明确要求不升级大版本。
深层安装涉及已有祖先权限，先核对原因和明确安全决策，不静默放宽机器级 DLL 保护。

### 翻页

组词中使用 `+` 下一页、`-` 上一页，包括主键盘 `+`（Shift+=）和数字小键盘加减。
主键盘 `=` 也作为下一页的便捷入口；Shift+- 为下划线，不作为上一页。
保留 PageUp/PageDown、现有候选导航。Ctrl/Alt/Win 组合及非组词状态仍直通，
不能因映射移除修饰键而吞快捷键。平台无关字符 `+/-` 入口与 Windows 映射行为一致。

### 候选窗

仅显示编号与候选文字，不绘制顶部拼音行或每项拼音注释；文档内 TSF 预编辑不移除。
保留 snapshot 中原始拼音和 canonical comment，供状态和学习使用，不能为隐藏文字改坏数据。
候选从左至右按行排列，空间不足换行；不再一候选一竖行。所有当前页候选均有可达的
绘制和命中矩形，不因布局而静默丢弃后半页。长文本单项裁剪/省略，不越界重叠。
当区域小到无法为整页（配置允许 1–99 项）提供最小可读且独立命中的布局时，
整体隐藏候选及页脚鼠标区域，不只截断部分候选；键盘选择与翻页继续有效。
布局通过空 candidates/footer 和零面积 preedit 表达该退化状态，不更改引擎页大小。
同一份平台无关布局驱动绘制、命中、DPI 与屏幕工作区约束；保留高亮和页脚，
上一页/下一页显示 `-`/`+`。窗口不激活，不抢文档焦点，不改宿主 DPI awareness。

### 安装分组件布局（替代上方自选目录必须承载机器 DLL 的约束）

用户将推荐方案交由主代理选择。采用系统组件与用户目录分离：
机器 DLL、注册工具、依赖许可及卸载器固定在 `{commonpf64}\Flower` 的受保护版本目录；
目录向导明确显示“用户文件目录”，可选本地盘的任意正常深层路径（受 Windows 路径长度、
重解析点及权限边界限制），例如 `D:\software\Flower`。不暗示 DLL 实际位于该处。
默认用户目录位于当前用户本地应用目录；不改任何已有父目录权限。

自选目录仅放设置程序、说明及程序许可的副本；不含被注册的 DLL。
这些文件只能通过安装成功后 `ExecAsOriginalUser` 调用安全系统目录中已核对哈希的
helper 写入，helper 明确拒绝提升 token，不由管理员进程直接写入可被用户替换的树。
命令只复制固定文件名，目标使用 create_new，拒绝覆盖和重解析点，不从自选目录执行
管理员操作。复制部分失败时仅清理本次确认创建的文件，不删除未知内容。
无法获取非提升原始用户时明确报告用户文件部署失败，不退回提升复制；保留安全系统
组件供卸载/修复，不能宣称完整安装成功。开始菜单公共入口仍指向安全系统目录。

卸载只运行安全目录中的已核对工具，保留用户自选目录副本和词典，明确说明可由用户
自行删除；不让提升卸载器递归遍历用户可替换的目录。已有注册依旧要求正常卸载旧版。

### 常用词组优先级

用户选择先按日常词组整体优化。增加由项目维护的日常词语优先层，明确它是人工使用
优先级而不是语料词频；只匹配真实已有词条，不造读音或新整句。规范词组、简拼候选
使用该层优先，其内继续按原词频、文字和读音稳定排序。非日常词仍全部保留。
为简拼碰撞，候选顺序改为完整全拼、整词简拼、完整组合、部分前缀；
完整真实词条不被任意组合字串压后。保留原始消耗、学习事件和只读共享快照契约。

### 缺失布局的兼容定位

定位仍只在 TSF 编辑会话中读取。优先有效的 GetTextExt（允许零宽、要求正高度）；
明确 clipped 时隐藏，不在不可见文本上显示。布局失败或空矩形时，尝试与当前 view HWND
关联的 GUI caret，并转换屏幕坐标；不能使用任意前台窗口的 caret。
仍无精确 caret 时，可用当前 view 的有效 GetScreenExt 左下边缘作粗粒度临时锚点，
明确不把它描述为精确插入符。无有效 view 区域则继续隐藏。
发布时保持现有 activation/context/focus epoch/revision 检查，失败不学习、不重写文档。
候选显示时只提升普通 Z 序，不使用永久 TOPMOST，不激活窗口；失焦仍立即隐藏。
诊断仅扩展固定阶段与 HRESULT，仍默认关闭、debug-only，不记录输入或窗口标题。
此修复覆盖已知布局/遮挡缺口，不以隔离回归宣称已复现或修复用户机器的全部 Edge 问题。
