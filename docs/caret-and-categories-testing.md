## 拼音内部编辑

1. 输入 `nihao`，高亮保持首项。连续按Left，文档中的拼音光标逐字符左移；
   到起点继续Left不进入已提交正文。
2. 把光标放在 `ni|hao`，输入 `x` 得到 `nix|hao`；Backspace恢复 `ni|hao`。
   按Delete得到 `ni|ao`，再输入 `h` 恢复 `nih|ao`。每次候选按新拼音刷新。
3. 输入有多个候选的 `shi`，Left移动光标，Right回到末尾的当次不移动高亮；
   再Right才选下一候选。高亮第二项时Left先回第一项，再Left才移动拼音。
4. 在内部光标处使用Up/Down或翻页，恢复光标到末尾后执行候选导航。
5. 先部分选择一个词，保留拼音后缀；移到后缀起点Backspace，
   上一段原拼音恢复且后缀保留。最终选择提交完整文本，取消不学习。
6. 在分音符两侧编辑，不能插入起点或相邻的重复分音符；删除不暗中改写其他字符。
7. 对包含补充平面汉字的已确认前缀，光标仍应准确定位在后面的ASCII拼音，
   不落在UTF-16代理对中间。该项有隔离原生回归，不要求用户寻找生僻字。

内部编辑暂停AI建议，回到拼音末尾停顿后恢复。已有按键预测、候选revision、
成功提交后学习和过期AI拒绝的规则继续有效。
