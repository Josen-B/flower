## 1. 已验证的单次拼音误输

这四类已使用真实内置词库首项和固定模型验证，不是仅向模型直接输入人工汉字。
正常输入、替换、交换、漏字和多字的对照如下：

| 类型 | 输入拼音 | 原首项 | 预期 |
| --- | --- | --- | --- |
| 正确输入 | `xianzaizainalishangban` | 现在在哪里上班 | 保持正确，不需建议 |
| 替换u/i | `xuanzaizainalishangban` | 选在在哪里上班 | `✓ AI` 现在在哪里上班 |
| 相邻交换 | `xainzaizainalishangban` | 喜爱嗯在在哪里上班 | `✓ AI` 现在在哪里上班 |
| 漏掉一个a | `xinzaizainalishangban` | 新在在哪里上班 | `✓ AI` 现在在哪里上班 |
| 多打一个a | `xiaanzaizainalishangban` | 下按在在哪里上班 | `✓ AI` 现在在哪里上班 |

可以分别在Edge普通输入框、新版记事本和自建测试文件的重命名中测试替换项。
拼音修复只对当前未提交内容做单次字母编辑的候选搜索，再由模型检查上下文；
不会自动修改已上屏正文，也不为纠拼音顺便改其他音节相同的人称或名字。

## 2. 原有汉字纠错与正确句

| 拼音或模型对照 | 预期 |
| --- | --- |
| `qingwenxianzainalishangban` | 原首项“请问现在那里上班”可建议“请问现在哪里上班” |
| `zhunishengrikuaile` | 原首项“住你生日快乐”可建议“祝你生日快乐” |
| `zhunishentijiankang` | 原首项“住你身体健康”可建议“祝你身体健康” |
| 正确句“我们选在哪里见面” | 不把“选”改成“现” |
| 正确句“他们选在这里上班” | 不把“选”改成“现” |
| 正确句“他正在认真学习” | 不把“他”改成“她” |

前三项是既有真实拼音链正例；后三项是固定模型的正确句对照。
输入对应拼音时，先确认普通候选与对照文字相同，再观察AI状态；
若词库首项本身不同，不能把它当作模型误改正确句的证据。

## 3. 通用选词记忆

本地选词记忆开启时，**每次成功选择一个完整普通候选，只与前一项交换一次**：
第二项下次第一；第三项下次第二，再选一次才第一。不是任意位置一次跳首。
以下规则对所有普通候选共用，不按“文体”文本硬编码。

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 数字选择 | 输入 `wenti`，按2选择“文体”，再次输入 `wenti` | “文体”排第一 |
| 方向＋Enter | 对另一组未学习的拼音，移动到第二项后Enter | 下次该项第一 |
| 方向＋空格 | 同上，使用空格确认 | 下次该项第一 |
| 鼠标选择 | 点击第二项，确认已提交，再输入相同拼音 | 下次该项第一 |
| 其他歧义词 | `shijie`或`shijian`选择第三个完整候选 | 下次只前移至第二 |
| 多次选择 | 再次选择刚从第三移到第二的候选 | 下一次第一 |
| 切换输入框 | 在另一个普通文本框重新输入相同raw | 使用本次激活已更新顺序 |
| 重启应用 | 正常退出并重新打开应用后输入同一raw | 使用已经保存的顺序 |
| 输入作用域 | 只学习 `wenti`，再试 `wt`、`went`、`wen'ti` | 不强行共享另一raw的排序 |
| 取消 | 输入后按Esc取消，没有选词提交 | 不产生本次排序变化 |
| AI建议 | 选择带 `✓ AI` 的项 | 不记录为普通个人排序 |

默认排序和已保存的个人顺序是两层：个人选择优先，不能用学习过的列表评估默认词频。
测试不同选择入口时宜使用不同拼音或记录当前顺序，不必清空已有个人数据。
保存失败会报告本地数据问题，不能把同激活内已前移当作重启后必然保存成功。

默认排序保留日常词的有限使用优先，同时不再让日常标签越过任意高频词。
原词库文字频率不是每个读音义项的独立频率，多音词仍可能需要个人选词记忆。

## 5. 保守边界

单次拼音编辑能召回候选不代表模型一定会展示。实测下列输入仍可能没有建议：

- `xianzaizainalishangbn`、`xianzaizainalishangbann`：词图能召回目标，但模型门槛未通过。
- `jintianxinqinghenhoa`：候选生成与结构/上下文门槛的组合尚未产生可发布建议。
- 两处以上拼写错误、显式音节边界修改、任意缩写恢复不属于本轮完整拼音修复承诺。

长中文候选继续换行/滚动完整显示，数字和鼠标选择应提交完整文本。
密码、PIN、明确私密范围、失焦或过期请求不学习、不发布旧AI建议；
这些反例由隔离原生测试验证，不需要用真实密码或个人文档进行试验。
