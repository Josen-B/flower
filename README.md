<h1 align="center">Flower</h1>

<p align="center">轻巧、离线、尊重隐私的 Windows 拼音输入法。</p>

Flower 希望让中文输入回归简单：打开应用、切换输入法，就能用拼音写下想说的话。
不需要账号，不依赖云端服务，也不上传输入内容。

## 功能

- **全拼输入**：输入 `nihao`，选择“你好”；支持用 `'` 明确区分音节。
- **首字母简拼**：输入 `nh` 查找“你好”、`zg` 查找“中国”，与全拼共用候选和选词操作。
- **连续选词与组句**：可以一次选择完整词句，也能分段选词、退格撤回或取消输入。
- **离线字词库**：内置常用汉字和词组，扩展字仍可翻页查找；另提供可选专名词库。
- **个人词典**：可导入、导出自定义词条和专业词库，按需启用。
- **可选本地学习**：默认关闭，提供明确的开关和清空入口；不联网同步。
- **候选窗设置**：支持页大小和主题调整，以及键盘、鼠标选词。

## 开始使用

Flower 当前支持 **Windows 10 / 11 x64**。使用构建产物中的 EXE 安装器，或按
[分发与安装说明](docs/distribution.md)使用 ZIP 包。

1. 安装 Flower；若已安装旧版，先按分发说明安全卸载，不覆盖正在使用的 DLL。
2. 在普通用户桌面，从开始菜单运行 **“启用 Flower（当前用户）”**。
3. 按 `Win + Space` 切换到 Flower，在文本框中输入拼音并选择候选。

Flower 不会自动替换默认输入法。保存设置或修改用户词库后，请重新切换到 Flower 生效。

### 常用操作

| 操作 | 按键 |
| --- | --- |
| 选择当前高亮候选 | `Space` |
| 选择对应编号候选 | 数字键或鼠标点击 |
| 删除拼音；剩余拼音为空时撤回上一段选词 | `Backspace` |
| 取消当前未提交的输入 | `Escape` |

首字母简拼按每个音节的第一个字母输入，目前支持整词简拼，不支持任意混合全拼与简拼。
离线组句不等同于语言模型，遇到歧义时可以自行选词。

## 隐私与当前状态

输入过程离线运行，无账号、无遥测、无云候选。学习数据仅保存在本机，且默认不启用；
密码、私密或无法确认安全的输入范围不会记录学习。

Flower 仍处于早期开发和兼容性验证阶段。测试安装包尚未签名，不同应用、DPI、安装及
升级场景仍需持续验证；自动测试通过不等于所有 Windows 宿主均已通过实测。

遇到问题时，请提供 Windows 版本、应用名称、Flower 版本、复现步骤及实际现象。
请勿提交私人文档、密码或其他敏感输入内容。

## 开发与贡献

Flower 使用 Rust 实现，Windows 平台通过 TSF 接入系统。欢迎提交问题、改进词库、
补充兼容性反馈或贡献代码。

```powershell
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --all -- --check
```

Windows 原生构建需要 Rust、MSVC C++ 构建工具和 Windows SDK；生成 EXE 安装器另需
Inno Setup。具体环境、组包和管理命令见 [分发说明](docs/distribution.md)，
行为约定见 [设计文档](design/)。
